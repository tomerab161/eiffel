# Architecture map

_Generated by `node agent-kit/scripts/map.mjs`. Do not edit above "Recent decisions"._

## Shape

- `packages/domain`: Zod schemas, constants and pure rules shared by both apps. Zod is its only runtime dependency.
- `apps/api`: Fastify. `modules/<module>/` = routes → service → repository → db. Outer: `shared/`, `plugins/`, `config/`, `db/`.
- `apps/web`: React + TanStack Router/Query. `features/<feature>/` (public entry `index.ts`). Outer: `clients/`, `components/`, `hooks/`, `types/`, `lib/`, `constants/`. `app/` wires feature entries to routes.
- Rules are enforced by `.dependency-cruiser.cjs` (arch gate). See AGENTS.md → Architecture.

## Packages

| package | path | depends on | purpose |
|---|---|---|---|
| `@app/domain` | `packages\domain` | — | Shared contracts and pure rules: Zod schemas, constants, rules. Zod is the only runtime dependency. No framework, no I/O. |
| `@app/api` | `apps\api` | `@app/domain` | Fastify HTTP API: modules of routes → service → repository, validated with domain Zod schemas, stored in MongoDB. |
| `@app/web` | `apps\web` | `@app/domain` | React web app: TanStack Router + Query, one folder per feature, talks to the API through clients/. |
